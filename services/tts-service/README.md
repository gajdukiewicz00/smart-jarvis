# TTS Service (Text-to-Speech)

Сервис синтеза речи - преобразует текст в аудио с помощью Piper TTS.

## Статус  
🚧 В разработке - будет реализован в следующих итерациях

## Планируемый функционал
- Синтез речи с помощью Piper
- Поддержка SSML
- Различные голосовые профили
- Streaming TTS для низкой латентности

## API
- `POST /api/v1/synthesize` - синтез речи
- `GET /health` - health check
- `GET /info` - информация о сервисе
