# DM Service (Dialog Management)

Сервис управления диалогом - принимает интенты от NLU и принимает решения о дальнейших действиях.

## Статус
🚧 В разработке - будет реализован в следующих итерациях

## Планируемый функционал
- Decision table для маппинга интентов на действия
- Контекст диалога и память
- Управление состоянием диалога
- Маршрутизация команд к соответствующим сервисам

## API
- `POST /api/v1/process-intent` - обработка интента
- `GET /health` - health check
- `GET /info` - информация о сервисе
