## 🔧 Технические детали

### Rust зависимости
- **cpal** - аудио I/O
- **hound, rodio, wav** - аудио файлы
- **zip, tar, flate2** - архивы
- **glob, ignore** - поиск файлов
- **screenshots, image** - скриншоты
- **sysinfo** - системная информация
- **jsonwebtoken** - JWT аутентификация
- **tokio-tungstenite** - WebSocket клиент

### Архитектура
- **Frontend:** React + Tailwind CSS
- **Backend:** Rust с Tauri
- **Аудио:** cpal для захвата/воспроизведения
- **Система:** sysinfo для мониторинга
- **Сеть:** reqwest для HTTP, tokio-tungstenite для WebSocket
